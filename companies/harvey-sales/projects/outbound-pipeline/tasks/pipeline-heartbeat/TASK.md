Run one heartbeat of the outbound pipeline.

Read four counts: open conversations waiting on us, approved sequences not yet sent, qualified prospects with no sequence, and fresh prospects. Apply the priority rule: handle replies, then send, then write, then prospect, then analyze. Dispatch exactly the work the counts call for as child issues, raise any approval that is due, and leave a one-paragraph note with the counts, the decision, and the reason.

Skip the run during quiet hours or when the board has paused sending.
